# SEC-0001: RustSec RUSTSEC-2026-0258 in h2

- Status: VERIFIED
- Date: 2026-09-07
- Category: SECURITY
- Evidence classification: CONFIRMED
- Affected scope: `Cargo.lock`; transitive `h2` dependency.

## Evidence
The protected dependency security workflow reported `h2` 0.4.15 as affected by RUSTSEC-2026-0258. Repository history records the repair in PR #75 / commit `bd7544bd18876c55f0469f2315667e9de23eea42`.

## Root Cause
The lockfile still resolved an `h2` release below the patched 0.4.16 baseline after the advisory became active.

## Fix / Decision
Use Cargo resolution to move `h2` to 0.4.16 or newer; PR #75 updated the locked dependency and also replaced yanked `chacha20` 0.10.0/0.10.1 with 0.10.2.

## Verification
The repaired dependency batch passed protected CI/security checks before merge. The final September maintenance `main` baseline `9a7b18f76dd6184785a4cf972daa1431ee07138f` has successful CI, supply-chain security, CodeQL, and secret-scan evidence recorded in `PROJECT_STATE.md`.

## Regression Protection
`Dependency & Supply Chain Security` runs `cargo audit`, `cargo deny`, and related supply-chain checks. The protected ruleset requires the security contexts and forbids bypass actors.

## Remaining Risk
Future advisories can affect new dependency versions; security maintenance remains continuous.

## NEXT ACTION
NONE — VERIFIED. Respond to future RustSec findings as new evidence, not by weakening this gate.

## DO NOT REPEAT
Do not add an advisory ignore merely to make CI green when a patched compatible release is available.
