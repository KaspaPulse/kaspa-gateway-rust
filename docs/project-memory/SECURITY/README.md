# SECURITY

Identifier pattern: `SEC-NNNN`.

Classify evidence as CONFIRMED, LIKELY, POTENTIAL, NOT REPRODUCIBLE, or FALSE POSITIVE; record precondition, impact, root cause, fix, verification, and protection.

Every record must carry an explicit lifecycle status, evidence, and a concrete `NEXT ACTION` when unresolved. Preserve prior verification instead of treating recurrence as an unrelated new issue.
